# The Challenge: one headline theorem per folder file

The Challenge states one headline theorem for each proof file `Grothendieck/FolderNN.lean`:
the declaration that the Lean appendix of [Hua, 2026](https://hexagonmath.org/2611.00125v1)
(`docs/lean/sections/*.tex` in the grothendieck-project repository) presents as the
folder's main verified statement, the boxed statement marked `\verifie{FolderNN}` and the
declaration cited after it when there is one. Where the appendix gives no single proved
theorem for the file (the headline is a definition, an instance, or a statement marked not
verified), the most representative proved theorem of the file is taken; these are marked
« representative » in the last column.

`Challenge.lean`, a single file that imports only Mathlib so that it compiles on its own,
has one section per folder file: it copies, verbatim and under the same names, the definitions,
structures and instances that the statement depends on, and states the theorem with `sorry`;
`Solution.lean` imports the library modules that prove them, and `comparator.json` lists
the theorems and the definitions that Comparator checks.
